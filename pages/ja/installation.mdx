# インストールと削除

[English](/installation)

## 必要な環境

検証対象の基本環境は、Windows 11 x64とMicrosoft 365のデスクトップ版PowerPointです。PowerPointは32ビット版と64ビット版が対象です。ネイティブARM64とWindows x86は対象外です。

MSIをインストールする前に、次のコンポーネントを端末全体で利用できる状態にしてください。

- .NET Framework 4.8以降。
- Microsoft Visual Studio Tools for Office（VSTO）Runtime。
- Microsoft Edge WebView2 Evergreen Runtime。必要な最低バージョンは、パッケージ付属の `DEPLOYMENT.md` を確認してください。

MSIは必要な環境を確認しますが、不足しているランタイムをダウンロードしません。ご自身で導入できない場合はIT管理者にご相談ください。

## Standalone MSI

1. [GitHub Releases](https://github.com/azure06/xkey-releases/releases)でインストールするパッケージを選びます。プレリリースはテスト用です。
2. ファイル名が **Standalone-x64.msi** で終わるファイルをダウンロードします。
3. PowerPointのすべてのウィンドウを閉じ、MSIを実行して管理者権限の確認を承認します。
4. PowerPointを開き直し、XKeyが読み込まれることを確認します。

XKeyとアップデーターが端末全体にインストールされます。利用者の設定はWindowsアカウントごとに保存されます。以降の更新については[アップデート](/ja/updates)をご覧ください。

## 会社が管理する端末 / Intune

会社のソフトウェア配布手順に従ってください。**Intune版**には自己更新機能がありません。`.intunewin` はIntuneにアップロードするファイルであり、ダブルクリックしてインストールするものではありません。

IT管理者はIntune版MSIを直接インストールすることもできます。[法人向け導入ガイド](/ja/enterprise)と付属の `DEPLOYMENT.md` をご確認ください。

## ClickOnce

案内された元のインストールリンクからセットアップを実行します。ClickOnceはインストールしたWindowsユーザーごとの仕組みです。同じ端末の別アカウントには、別のインストールが存在する場合があります。

MSIへ移行する場合は、対象となる各ユーザーのアカウントで、XKeyと確認できたClickOnceインストールを削除してから、端末全体のMSIを配布してください。IT管理者向けに移行スクリプトを用意しています。ClickOnceキャッシュ全体を削除しないでください。

## アンインストール

PowerPointを終了し、Windowsの「インストールされているアプリ」からXKeyを削除します。会社の管理対象端末では、会社の削除手順に従ってください。Standalone MSIを削除すると、同梱のアップデーターも削除されます。アップデーターは独立した常駐サービスではありません。

利用者の設定、管理者が指定した更新チャネル、診断用キャッシュは保持されます。ClickOnceの削除は、そのインストールを所有するユーザーのアカウントで行ってください。

## XKeyが表示されない場合

まずインストールエラーや不足しているランタイムを確認してください。PowerPointがアドインを無効化している場合や、既存のClickOnce・開発用インストールと競合している場合もあります。Officeのレジストリを削除する前にサポートへご相談ください。

[問題を報告する際](https://github.com/azure06/xkey-releases/issues)は、XKeyのバージョン、インストール方式、Officeの32/64ビット、エラーメッセージをお知らせください。共有するログから個人情報や認証情報を取り除いてください。
