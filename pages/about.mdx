# About XKey releases

This public repository distributes XKey for Microsoft PowerPoint and hosts its installation documentation. Application source is maintained separately in a private repository.

Standalone and Intune packages are published as signed assets on [GitHub Releases](https://github.com/azure06/xkey-releases/releases). This website continues to serve documentation and legacy ClickOnce files.

For installation help, start with the [installation guide](/installation). Report reproducible problems through [GitHub Issues](https://github.com/azure06/xkey-releases/issues), after removing private information from any shared logs.
