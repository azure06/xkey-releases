# Installation

Download the package from [XKey's GitHub Releases](https://github.com/azure06/xkey-releases/releases). Check the release notes and its attached deployment guide before installing a prerelease.

## Requirements

The current test baseline is Windows 11 x64 with Microsoft 365 desktop PowerPoint, either 32-bit or 64-bit. Install these prerequisites machine-wide first:

- .NET Framework 4.8 or newer.
- Microsoft Visual Studio Tools for Office (VSTO) Runtime.
- Microsoft Edge WebView2 Evergreen Runtime, meeting the minimum version in the release's deployment guide.

The MSI checks prerequisites but does not download them. Native ARM64 and Windows x86 are outside the supported baseline.

## Standalone

1. Download the asset ending in **Standalone-x64.msi**.
2. Close all PowerPoint windows and run the MSI. Approve the Windows administrator prompt.
3. Reopen PowerPoint and verify that XKey loads.

The Standalone package includes the updater. Future updates require your approval and wait for PowerPoint to close. See [Updates](/updates).

## Managed installation

Use the **Intune** distribution when IT controls XKey. The `.intunewin` file is an upload container for Intune, not an installer you double-click. A direct Intune MSI installation is possible; follow the attached deployment guide. See [Enterprise deployment](/enterprise).

## Removal

Uninstall XKey through Windows Installed apps. Removing the Standalone MSI also removes its bundled updater; it is not a separately installed service. User settings, update-channel configuration and diagnostic caches are preserved. Intune installations should be removed through the company's management process.

## Troubleshooting

If installation reports a missing prerequisite, install the required machine-wide runtime and retry. If XKey does not load, check whether PowerPoint disabled the add-in or whether an older ClickOnce/developer installation conflicts with it. Avoid deleting Office registrations or the whole ClickOnce cache as a general fix.

When [reporting a problem](https://github.com/azure06/xkey-releases/issues), include the XKey version, distribution, Office bitness and the error message. Review logs before sharing them and remove personal information or credentials.
